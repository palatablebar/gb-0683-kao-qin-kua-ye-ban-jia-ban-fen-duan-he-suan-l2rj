# 夜班工时与工资

班次属于shift_day；计划结束时间不大于开始时间时跨到次日。打卡是带偏移的时间，先存UTC，再用Asia/Shanghai拆分实际日历日。休息区间按夜班日期归属处理，先从实际工作区间扣除。单班最多18小时，打卡须为整分钟。缺IN或OUT整班隔离，不猜补卡。

按实际日历日判断法定假日、周末，法定假日优先3倍、周末2倍、工作日8小时内1倍、超过8小时1.5倍；正常分钟按同员工同日累计，跨班片段共享阈值。参数holidays可传日期列表，默认仅2026-10-01。金额按片段Decimal计算到分，paid为实发工资，差额为应发减实发。此规则用于样例计算，不替代当地劳动法规。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

同一员工/归属日/方向的最高版本若有时刻、时薪、班次、休息或实发金额冲突，则整班隔离；选中IN与OUT的时薪、班次起止与休息起止也必须完全一致。

## 加班预支与预支结清（M8/M9）

预支参数 `as_of`（带时区 ISO 时间，必填）与 `period_key`（期间键，缺省 PERIOD）。预支依据两档：`CLOSED` 表示进出打卡齐全且下班不晚于 as_of，按整班全部计薪片段预付；`PARTIAL` 表示跨夜班后半夜尚未闭合（缺 OUT 或 OUT 晚于 as_of），仅取结束时刻不晚于 as_of 的已完成计薪片段预付。未闭合且 as_of 前无任何完整片段的班次跳过、不产生预支，禁止按排班工时预付。预支单幂等键为 `(period_key, run_id, as_of, basis)`，同源同口径重跑返回原单。

结清单按 `(员工, 班次)` 逐行对应：`final_amount` 来自月底完整数据的计薪证据求和；`advance_amount` 汇总该期间本班所有实际发放过的预支（含被取代旧版）；`clawback=max(advance_amount-final_amount,0)`；`net_payable=final_amount-advance_amount`，负数不付款而转入待扣回。恒等式：最终应付 + 待扣回 = 预支已付 + 本次实付（本次实付只累加正净付行）。

预支失效：同一来源哈希上存在更晚创建的预支单时，较早单标记 `SUPERSEDED` 并记录 `superseded_by`，关系冻结不被后续结清改写；其余预支随结清置 `SETTLED` 并指向最新结清单。结清来源哈希变化即生成新版本，旧结清版本转 `SUPERSEDED`；同来源且关联预支集合相同的重跑幂等复用。结清写入在单事务内覆盖结清单、明细、关联、预支状态与事件，任一失败整体回滚，旧 CURRENT 版本不被破坏。

对平核查五项：最终应付等于计薪证据独立求和、计薪证据等于 m5 业务总额、预支逐行合计等于预支单总额、资金恒等式、期间全部预支单均被关联。任一不过 `balanced=false`，拒绝封存与 CSV 导出（409 UNBALANCED）。原始打卡字节、参数按来源哈希存 `source_snapshots`，结清单与预支单保留来源哈希，全部历史可追溯；页面与导出均呈现同一落库版本。
